# Hermes Mobile — project conventions

Native SwiftUI + TCA iOS companion for a self-hosted Hermes Agent. A thin remote
client; no agent logic on the phone. See `README.md` for the feature overview and
`docs/plans/completed/2026-06-09-hermes-ios-mvp.md` for the full design history.

## Layout

- **`HermesKit/`** — local SPM package: all models, dependency clients, and TCA
  reducers. This is where logic lives. Built/tested with `swift test` (no simulator).
- **`HermesMobile/`** — thin app target: SwiftUI views only, generated by Tuist.
  `Project.swift` is the source of truth; the `.xcodeproj`/`.xcworkspace` are
  generated and gitignored.
- **`HermesMobileTests/`** — iOS XCTest target for SwiftUI snapshot tests (separate
  from the SPM suite).
- **`Probe/`** — throwaway protocol probe (gitignored fixtures).

## Conventions

- **Logic in `HermesKit`, views thin.** Keep view files declarative; push behavior into
  reducers. New testable logic goes in the package, not the app target.
- **Clients are `@DependencyClient` structs** with `liveValue` + a `testValue` (no-op or
  in-memory). Inject `URLSession`/transports for testability. Never call
  `UIKit`/`Security`/`URLSession` directly from a reducer — go through a client.
- **The gateway socket** is a single long-running cancellable effect funneling every
  event through one `.gatewayEvent` action; outbound JSON-RPC calls are discrete
  one-shot effects. **Reconnect/backoff lives in the reducer**, not the client.
- **Streaming has no message id** (verified by the M0 probe) — the fold tracks a single
  in-flight assistant row. `session_id` is on the event *frame*, not the payload.
- **Decode leniently; never crash on unknown events** — unknown `type` → `.unknown`.
- **Commit messages**: capitalized verb, no conventional-commit prefixes, concise.

## Testing (required for every change)

- TCA reducers: `TestStore` + `@Dependency` overrides + `TestClock`. Event-reduction
  tests are the highest-value suite.
- `swift test` buffers when piped — use `script -q /dev/null swift test --package-path HermesKit`
  for live output (or `make test`).
- Snapshot tests: `make snapshot` (assert) / `make snapshot-record` (re-record). They
  render real views and **catch view regressions reducer tests can't** — re-record when
  UI changes intentionally. Row timestamps are pinned for determinism.

## Gotchas

- **Tuist only forwards `TUIST_`-prefixed env vars** to the manifest. Friendly names
  (`DEVELOPMENT_TEAM`, `HERMES_DEFAULT_SERVER_URL`) are translated by the run scripts;
  for direct `tuist generate`, use `TUIST_DEVELOPMENT_TEAM` / `TUIST_SERVER_URL`.
- **New source files need `tuist generate`** before an `xcodebuild` app build picks them
  up (sources are globbed at generation time).
- **`@Sendable` effect closures** must capture dependencies explicitly (`[dismiss]`,
  `[gateway]`) — the reducer `self` is not `Sendable`.
- TestFlight **export must use manual signing** (cloud/API-key signing fails on export).
